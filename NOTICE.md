# Third-party components and asset provenance

LANBridge Pro source uses Python 3.12, PySide6/Qt for Python, pywin32, SQLite,
PyInstaller (build-time), pytest and Ruff (development). Their licenses remain
with their respective projects. PySide6/Qt distribution requires compliance
with the applicable LGPL/GPL or commercial license; retain bundled license
notices and review your distribution obligations before commercial release.
PyInstaller's bootloader exception and each dependency's current notices should
be retained with the release bundle. No bundled dependency license is replaced
by this notice.

All included UI SVGs and the application SVG/PNG/ICO are original geometric
assets generated by `tools/create_assets.py`; they do not copy a third-party
brand/logo. Pillow is only needed to regenerate the ICO, not at runtime. Microsoft
PowerShell and Robocopy are Windows system components, not redistributed here.

The project ships no telemetry client, cloud account requirement, secret key,
embedded credential, or automatic internet update mechanism. Runtime network
operations are local SMB, optional LAN discovery, and requested diagnostics.
